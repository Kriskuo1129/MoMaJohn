# 台灣夜市摸麻將（MoMaJohnNM）

純 HTML、CSS、JavaScript 製作的一頁式夜市麻將遊戲，不需後端或建置工具即可執行。

## 本機執行

直接以瀏覽器開啟 `index.html` 即可遊玩。若瀏覽器對本機檔案有限制，也可在專案根目錄啟動任一靜態伺服器，例如：

```powershell
python -m http.server 8000
```

再開啟 `http://localhost:8000/`。

## 專案檔案

- `index.html`：遊戲頁面與 Modal 結構。
- `style.css`：桌面、手機、棋盤、事件及動畫樣式。
- `game-config.js`：點數、事件權重與額外下注設定。
- `game.js`：牌組、狀態機、點數結算、事件、補牌及統計邏輯。
- `EVENTS_BETS_SCORING.md`：供討論用的事件、下注與點數規則整理。
- `TECHNICAL_FUNCTIONAL_SPEC.md`：專案唯一的技術與功能規格，後續直接更新此檔。
- `RELEASE_NOTES.md`：給玩家閱讀的更新說明。
- `WORK_REPORT.md`：本次修改與驗證紀錄。

## 核心規則

- 每局先累積「本局倍率前數值」，局末才統一乘上最終倍率。
- 玩家 HUD 直接顯示倍率後的本局點數；倍率前數值只保留在內部結算資料。
- 額外下注在倍率結算後獨立計算，不受倍率影響。
- 一般事件只改變本局點數；特殊事件可改變次數、倍率、棋盤或流程。
- 標準模式的兩張事件牌以「事件 A／事件 B」區分棋盤位置，但仍共用同一事件池。
- 「我要聽牌」下注成功 +5 點、失敗 -5 點，且不受倍率影響。
- 總點數最低為 0，本局倍率前數值則可以是負數。
- 補牌選擇命中聽牌缺牌時會立即成功，不必繼續選滿三張。
- 手機版下注入口位於 HUD 與棋盤之間；摸牌後仍可唯讀查看倍率、下注與本局狀態。
- 「說明」會顯示點數規則，標準模式另由事件設定動態產生事件一覽。
- 所有牌面使用 Unicode 麻將字元與 CSS，不含圖片素材。

## 部署

此專案可直接使用 GitHub Pages：Repository 的 **Settings → Pages**，將來源設為 **Deploy from a branch**，選擇 `main` 與根目錄 `/ (root)` 後儲存。
